# 🤖 Bot de Botoneras Automáticas para Telegram

Bot automatizado para gestionar botoneras de canales de Telegram.

## 🚀 Características

✅ **Para usuarios:**
- Agregar canales a botoneras automáticas
- Solicitar aprobación de canales
- Ver estadísticas de canales
- Gestión múltiple de canales

✅ **Para administradores:**
- Crear y editar botoneras
- Aprobar/rechazar canales
- Enviar mensajes globales
- Ver estadísticas detalladas
- Configurar userbot automático
